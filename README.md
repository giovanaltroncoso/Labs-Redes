# Simulação de Rede

Projeto de simulação de rede desenvolvido no Cisco Packet Tracer para validar a conectividade entre computadores.


#### O que foi feito:
- Topologia: Estrutura dividida em camadas de Núcleo (Roteador), Distribuição (Switch) e Acesso (Switches para os setores LAB e SEC).

- Configuração: Definição de endereços IP, máscaras de sub-rede e gateways nas máquinas.

- Testes: Conexão física dos dispositivos e validação de pacotes para garantir a comunicação correta.
